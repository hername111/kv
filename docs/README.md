# 项目文档

## 维护约定

- 功能或文件格式发生变化时，同步更新 `architecture.md`。
- 构建、测试或目录规则发生变化时，同步更新 `development.md`。
- 已失效的计划稿和工具生成资料不在此目录长期保留；确需归档时放入单独的 `archive/`，并标明失效日期。
- 项目入口、安装和运行方式以仓库根目录的 [README](../README.md) 为准。
